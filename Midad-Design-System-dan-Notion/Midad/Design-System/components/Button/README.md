# Button

Tombol aksi dengan tepi 3D yang "turun" saat ditekan. Label tombol berbahasa Arab. Kelas dasarnya `.md-btn`.

- **Utama** (`.md-btn`, brand): satu per layar, untuk aksi inti seperti تَحَقَّقْ (periksa), مُتَابَعَة (lanjut), atau اِبْدَأْ (mulai).
- **Sekunder** (`--secondary`): aksi alternatif, misalnya تَخَطَّ (lewati) atau اِسْتَمِعْ مَرَّةً أُخْرَى (dengar lagi).
- **Hadiah** (`--gold`): hanya untuk membuka hadiah.
- **Sukses / Bahaya** (`--success`, `--danger`): hanya dipakai di FeedbackSheet.
- **Ghost** (`--ghost`): aksi tersier.
- `--block` membuat tombol selebar kolom. Di layar pelajaran, tombol utama selalu `--block` dan menempel di bawah.
- Nonaktif: atribut `disabled`. Tombol تَحَقَّقْ tetap nonaktif sampai pengguna memilih jawaban.

Label berupa kata kerja perintah (fi'l amr), 1–2 kata, dengan harakat di level pemula. Tanpa uppercase dan letter-spacing. Terjemahan label tombol tidak ditampilkan; maknanya dipelajari lewat onboarding dan glosarium.

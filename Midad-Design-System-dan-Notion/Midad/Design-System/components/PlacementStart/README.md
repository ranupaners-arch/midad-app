# PlacementStart

Layar onboarding setelah pengguna memilih bahasa ibu dan maskot. Di sini pengguna memilih mau **mulai dari nol** atau **ikut tes tahdid mustawa** (اِخْتِبَارُ تَحْدِيدِ المُسْتَوَى).

- Tes bersifat adaptif, sekitar 10–15 menit, berisi soal dengar, baca, dan susun.
- Hasilnya menempatkan pengguna di **awal salah satu jilid** (level 1, 9, 17, 25, 33, 41, 49, atau 57). Lihat bagian **Rihlah**.
- Level sebelumnya ditandai تَجَاوَزْتَهُ (dilewati), dan tetap bisa dibuka untuk mengulang.
- Layar hasil tes: maskot berlayar langsung ke wilayah hasil tes dengan kendaraan wilayah itu (MascotLoader, mode hijrah).
- Tes bisa diulang dari pengaturan, sekali setiap 30 hari.

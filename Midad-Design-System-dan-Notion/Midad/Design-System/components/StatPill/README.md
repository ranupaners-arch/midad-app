# StatPill

Pill statistik di top bar: **فانوس Fanus** (lentera = streak), **تمر Tamr** (kurma = mata uang), dan XP.

- Urutan (RTL, dari kanan): lentera → kurma → XP.
- Angka memakai angka Latin (0–9) dengan gaya `num`, biar terbaca cepat. Angka Arab (٠–٩) dipakai di teks pelajaran.
- Ikon lentera memakai `lantern` dan angkanya `lantern-ink`. Kurma memakai `date`. Ikon XP memakai `gold-strong`.
- `is-off`: lentera padam karena hari ini belum belajar.
- `aria-label` ditulis dalam bahasa Arab, ditambah terjemahan untuk pembaca layar sesuai bahasa ibu pengguna.

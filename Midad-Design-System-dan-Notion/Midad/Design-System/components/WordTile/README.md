# WordTile

Tile kata Arab untuk soal "susun kalimat". Diketuk untuk dipindah dari bank kata ke area jawaban, dan sebaliknya.

- Urutan RTL: kata pertama ada di kanan.
- Area jawaban `.md-answer-line` berupa garis bawah.
- Tile yang sudah dipakai tetap di posisinya dengan class `is-used`, supaya bank kata tidak bergeser.
- Tinggi minimum `touch-min`, font `ar-md`.

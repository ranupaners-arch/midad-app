# 08 · Konteks Lomba & Timeline

## Lomba "Abjad" (أبجد) 2026

Lomba teknologi untuk inisiatif bahasa digital dalam rangka Hari Bahasa Arab Sedunia 2026, diselenggarakan oleh Sultan Qaboos Institute for Teaching Arabic to Non-Native Speakers. Tema tahun ini: اللغة العربية والتنوع الثقافي (bahasa Arab dan keberagaman budaya).

|  |  |
| --- | --- |
| **Batas pengumpulan** | 2026-12-05 (Sabtu) |
| **Pengumuman** | 2026-12-18 |
| Hadiah | Juara 1: 300 Rial Oman + sertifikat + plakat · Juara 2: 250 · Juara 3: 150 |
| Peserta | Individu/tim boleh berkompetisi. Lembaga hanya pameran |

### Yang wajib dikumpulkan

- [ ] Link aplikasi yang bisa dibuka juri (rencana: web app/PWA)
- [ ] Video demo **maksimal 3 menit** (cara kerja, tampilan, nilai edukatif)
- [ ] PDF penjelasan: kartu profil inisiatif + rencana pengembangan
- [ ] Ringkasan 150–250 kata dalam bahasa Arab
- [ ] Pernyataan orisinalitas (tidak melanggar hak kekayaan intelektual)

### Isian form

- Jenis: aplikasi HP + game edukasi interaktif
- Target: penutur non-Arab, level pemula
- Status: prototipe yang bisa dites

> ⚠️ **Hak cipta kitab:** materi mengikuti *Al-'Arabiyyah Baina Yadaik* (penerbit Arabic For All). Tulis sendiri semua soal, kalimat, dan dialog dengan mengikuti urutan bab. Email permohonan izin rujukan kurikulum ke [info@arabicforall.net](mailto:info@arabicforall.net) (WhatsApp +966 55 458 4598) sudah didraf.

## Scope demo lomba (MVP)

Satu alur yang mulus, bukan banyak fitur setengah jadi:

1. Pilih bahasa ibu → buat maskot → mulai dari nol
2. Peta Rihlah (Nusantara, pinisi)
3. 2–3 wahdah: mufradat, hiwar dengan انظر واستمع وأعد, latihan, hint
4. Ujian wahdah → naik level (animasi berlayar) → hadiah kurma + skin

Fitur seperti mentor, rute EN, dan kitab 2–4 cukup **masuk rencana pengembangan** di PDF.

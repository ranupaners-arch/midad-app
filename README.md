# Midad (مِداد)

Aplikasi belajar bahasa Arab bergaya game. Lomba Abjad 2026 (deadline 5 Des 2026).

| Folder | Isi |
|---|---|
| `design-system/` | **Sumber kebenaran** design system: token, komponen CSS, maskot, data rute & kurikulum |
| `docs/notion/` | Salinan Markdown halaman Notion "Midad — Design System" |
| `paket-aset/` | Aset siap pakai. **Hasil build, jangan diedit langsung** (`node scripts/build-paket.mjs`) |
| `scripts/` | Skrip build token, validasi data, paket aset |
| `app/` | Aplikasi (Vite + React + TS), menyusul |

Kurikulum: 4 marhalah (A1–B2) × 16 wahdah = 64 level, diselaraskan dengan CEFR. Lihat `docs/notion/09-Kurikulum-CEFR.md`.
Riwayat arsip awal: `docs/ARSIP-20NOV.md`.

# Ikon

Ikon khas Midad. Semua ikon 24px memakai garis 2px, ujung bulat, dan `currentColor`, jadi warnanya ikut CSS `color`.

**Ikon khas اُنْظُرْ وَاسْتَمِعْ وَأَعِدْ: tiga lencana terpisah, satu per langkah.** Masing-masing punya warna dan bentuk sendiri, jadi langsung dikenali bahkan tanpa membaca labelnya. Ketiganya selalu tampil berurutan (kanan → kiri dalam RTL).

| Langkah | Lencana 64px | Ikon 24px | Warna | Bentuk |
|---|---|---|---|---|
| اُنْظُرْ (lihat) | `look-badge.svg` | `look.svg` | teal (brand) | mata terbuka dengan garis sinar |
| اسْتَمِعْ (dengar) | `listen-badge.svg` | `listen.svg` | emas | telinga + gelombang suara |
| أَعِدْ (ulangi) | `repeat-badge.svg` | `repeat.svg` | kurma | mikrofon dikelilingi dua panah ulang |

Dipakai di: header dan chip langkah ListenRepeat, lencana pelajaran di peta, dan tutorial onboarding.
- `hint-drop.svg` — **قَطْرَة** (tetes tinta) = satu bantuan/hint.
- `mentor.svg` — tanya mentor.

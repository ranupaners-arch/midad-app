# Cover

Kartu sampul (960 × 288) untuk halaman depan design system interaktif. **Bukan komponen aplikasi**: tidak punya class `md-`, dan stylenya ditulis langsung di `preview.html`.

- Kiri: wordmark "Midad" (Nunito 800) dan tagline Arab.
- Kanan: ilustrasi geometris berwarna token (`brand`, `gold`, `date`, `ink`), jadi ikut tema terang/gelap.
- Layout memakai `left` karena kartu ini LTR (`lang="id"`). Jangan dijadikan acuan untuk layar aplikasi yang RTL.

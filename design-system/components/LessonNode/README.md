# LessonNode

Satu titik di peta perjalanan **رِحْلَة Rihlah**. Unit adalah pelabuhan (**مَحَطَّة Mahattah**), dan node adalah pelajaran di dalamnya.

- `--current`: pelajaran berikutnya, dengan label mengambang اِبْدَأْ. Hanya boleh ada satu di layar.
- `--done`: emas dengan ikon bintang (تَمَّ).
- `--locked`: abu-abu dengan gembok (مُغْلَقٌ) dan `aria-disabled`.
- `--chest`: peti harta (كَنْزٌ) berwarna kurma.
- Ukuran `node-size`. Jarak vertikal `space-10`, disusun zig-zag mengikuti jalur kapal.

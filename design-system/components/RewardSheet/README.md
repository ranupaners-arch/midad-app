# RewardSheet

Layar hadiah setelah pengguna **lulus ujian**. Maskot pengguna tampil dengan ekspresi `cheer` sambil memakai skin yang baru didapat.

- Isi: judul keberhasilan, skor, lalu kartu hadiah (kurma, skin/item dengan bingkai tingkatnya, peti).
- Judul per ujian: نَجَحْتَ فِي اخْتِبَارِ الوَحْدَةِ! · …فِي الاخْتِبَارِ النِّصْفِيِّ! · …فِي الاخْتِبَارِ النِّهَائِيِّ! (pakai bentuk نَجَحْتِ untuk pengguna perempuan).
- Tombol: setelah ujian wahdah → لِلْوَحْدَةِ التَّالِيَةِ. Setelah nisfi/nihai → إِلَى الرِّحْلَةِ التَّالِيَةِ (masuk animasi hijrah).
- Hadiah langsung tersimpan. Skin baru bisa langsung dipakai lewat tombol kecil "البَسْهَا الآنَ" (pakai sekarang).
- Peti (كَنْز) dibuka dengan animasi terpisah dan berisi item common acak.

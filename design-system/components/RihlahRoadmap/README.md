# RihlahRoadmap

Peta jalan (roadmap) **per rute bahasa ibu**: 8 etape (1 etape = setengah marhalah = 8 wahdah/level), lengkap dengan kendaraan, wilayah, daftar pelabuhan, dan penanda penting.

- Tombol **ID / EN** mengganti rute. Rute ID berangkat dari Nusantara, rute EN dari Britania.
- Penanda di tiap etape:
  - 🌙 **الوُصُولُ إِلَى بِلَادِ العَرَبِ** — tiba di dunia Arab (level 17)
  - **بِدُونِ تَشْكِيلٍ** — mode tanpa tasykil mulai (level 41)
  - **الاخْتِبَارُ النِّصْفِيُّ / النِّهَائِيُّ** — tes di akhir setengah marhalah / marhalah
- Data: `assets/rihlah/routes.json`. Bahasa ibu baru cukup menambah 2 etape pembuka dan titik masuk ke dunia Arab.
- Di aplikasi, roadmap ini dibuka dari peta Rihlah (tombol "خَرِيطَةُ الرِّحْلَةِ"). Etape yang sudah lewat diberi centang, dan etape saat ini menampilkan maskot pengguna di kendaraannya.
